## 本轮失败与修复记录

1. 核对发现 drain 超时误计候选故障，现改为 drain_busy 延期并明确恢复旧实例；单独回归通过。
2. stable 落盘中 UI 丢失时原实现可能清掉 previousStable 后选错引用，现保存事务旧引用、提交后复查，失败收敛回旧包；单独回归通过。
3. 回滚异步验包期间缺少 busy 保护，现一次只接受一个事务；并发回归通过。
4. 持久化钩子遗漏目录 sync 前与包目录切换/锁同步，已补齐并按实际轨迹逐调用注入。
5. GC 只看账本、遗漏尚存在实例引用，已加入运行引用；引用 GC 与容量测试通过。
6. 存储更新层新增同序号 digest 不可变化校验，防止高水位同序号异内容；测试通过。
7. 首次最终 typecheck 发现 JS liveReferences 推断 never[]，补充 string[] 类型注释后重跑通过。未忽略错误。
