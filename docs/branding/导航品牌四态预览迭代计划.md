# 导航品牌四态预览迭代计划

日期：2026-10-31。范围：KyCRM Core、Host、平台与机构品牌表单、组件示例。保持已有素材 ID、权限、平台保存和机构草稿发布语义，不修改数据库或派生项目。

## 任务与验收

- [x] T1 素材规则：展开使用明暗文字 LOGO 和可选 AI；收起使用应用图标，无 AI；缺失或失败按当前品牌生成应用图标。平台和工作区身份传递 icon，不再用裸短名称代替应用图标。
- [x] T2 共享四态预览：每个明暗分组均有展开、收起导航片段；固定展开 177px、收起 80px 品牌区，两侧16px；不继承实际导航收起状态；明暗变量独立，窄屏横向查看实际尺寸。
- [x] T3 表单入口：保留单一应用图标上传卡，删除两张独立文字上传卡，亮暗文字上传、更换、恢复默认入口移入对应预览组；保留透明横向 PNG、4MB 限制和原有素材，不对图片拉伸或反色。
- [x] T4 一致性：平台和机构共用预览布局，组件中心展示真实四态与可复制用法；品牌规范同步更新。
- [x] T5 验证：不同品牌、应用图标、AI开关、亮暗文字素材、缺失和失败降级、全局明暗隔离及收起宽度隔离；Host及依赖构建、类型检查、组件索引与回归测试；本地真实组件浏览器验收。

## 批次和交付边界

先完成素材契约与导航，再改四态预览和两个表单，最后更新示例规范并运行验证。构建、浏览器、线上部署分别记录；本次实现不自动修改线上品牌配置或发布安装包。

## 本轮执行结果

- T1：Core 增加 BrandIcon 与 icon 素材契约；平台公开素材及工作区有效品牌接入。应用图标保留原色，缺失时生成，图片失败时继续降级。
- T2–T3：Core 增加无业务请求的 BrandNavigationPreview，平台/机构表单复用四态布局；文字素材操作移入对应预览组。历史素材字段、资产ID和保存/发布流程保留。
- T4：组件中心完整品牌示例展示真实四态，公开导出、源码索引及品牌规范同步。
- T5：Host及依赖完整构建和类型检查通过；组件中心10项测试通过，新增四态片段、双图标、双AI、固定尺寸/独立色板以及图标失败降级断言；Core正式包入口回归通过。
- 本地浏览器：真实平台品牌表单出现四态和单一图标卡，只有两处文字上传入口；全局暗/亮切换前后，商务蓝预览分别保持 rgb(37,99,196) 与 rgb(139,184,255)。全局侧栏变量设为80px时，两组展开预览内容区仍为145px，未缩成短标。

边界：浏览器使用虚构数据，未上传或保存真实平台/机构素材，未完成真实机构发布的端到端验收；未部署。新功能的线上检查应在单独发布后执行，不能以本地测试代替。

## 用户复核修订：四个独立入口与直接文字降级

- 四个预览项标题右侧分别提供上传、更换、恢复默认，不共用明暗组的上传按钮；移除上方独立素材卡。
- 四态对应字段为 wordmarkId、iconId、wordmarkDarkId、iconDarkId。暗色收起新增 iconDarkId，沿用 JSON 配置和资产存储，无数据库结构迁移。
- 未上传或标记为历史自动生成时，直接按品牌名/图标文字排版，不再先生成带内边距的 PNG。恢复默认清空对应自定义素材引用，不清除其他三个素材。
- 收起品牌区48px内展示48px自定义图标或直接缩放文字，只保留导航容器的16px边距，避免两层留白。
- 平台资产公开校验、机构资产归属校验、发布公开标记、有效品牌、变更审计与旧请求字段缺省保留均补齐 iconDarkId。旧客户端未携带字段时保留已有暗色图标，显式空字符串才清除。
- 本轮包含组织服务和共享品牌契约改动，后续发布不再属于 Web-only；应联合发布 org 与 Web 并分别验收。

## 客户端桌面 LOGO 场景补充

独立保留“客户端桌面 LOGO”卡，使用原 iconId 字段，供客户端打包时选用，场景为桌面快捷方式、应用启动器、Dock/任务栏。保存素材不自动改变已安装客户端系统图标；当前客户端未检索到运行时品牌图标注入，不能宣称已支持热更新桌面图标。

四个导航入口与桌面素材独立：亮色展开 wordmarkId、暗色展开 wordmarkDarkId、亮色收起 navIconId、暗色收起 iconDarkId。四个导航项未上传时直接显示文字，桌面图标仍可生成默认正方形素材。新增 navIconId 的归属校验、公开标记、有效品牌、审计及旧请求字段保留规则与 iconDarkId 一致。
