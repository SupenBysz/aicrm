## 已验证与参考缺陷

主补丁单独可通过管理端39项测试。补齐02参考源码后，插件40项交叉合同测试通过。

引擎精选7个测试文件运行了43项测试：42项通过，1项失败。失败位于`script-runtime-sdk-contract.test.mjs`，仍读取`../preload/public-script-api.ts`；参考HEAD已删除该文件，公共API实现位于`web-window.ts`。这是参考源码的过时测试路径，未通过创建占位文件掩盖，也未把失败计为通过。

隔离源码组合的桌面typecheck还要求安装02的新增桌面依赖。首次检查发现React/ReactDOM/Antd未安装和缓存桥消费端缺失；02随后补充锁定参考`plugin-host-bridge.ts`，但尚未完成桌面依赖安装、全量编译与真实GUI验证。本组状态明确为“参考待整合”。

## 迭代需求

1. 先应用01，验收平台脚本CRUD、双资产版本、公共资源、权限和服务端解析。使用隔离数据验证接口，无需先迁入店铺业务。
2. 将02的引擎及契约整合到当前桌面宿主，协调preload/renderer/Host/Core的命令、事件、快照与清理。保留sender gate、来源白名单和紧急停用；只迁入本功能实际需要的依赖。
3. 单独接入Web窗口和DD_LOGIN，确定当前项目对应登录空间API；没有对应业务模块时明确不启用该消费入口。店铺登录空间的迁移和加密同步属于独立功能，不能用管理模块补丁替代。
4. 修正已证实的参考过时测试路径，并独立更新桌面依赖和锁文件，完成typecheck/build和纯运行时测试。
5. 使用无真实账号的本地页面夹具完成Electron注入验收，再验证当前工作区的真实授权入口；只有消费端验收通过才可称为完整脚本注入功能。

## 验收清单

| 场景 | 必须观察到的结果 |
| --- | --- |
| 权限隔离 | 非平台不能访问平台管理；无源码权限不能读取业务源码；公共资源与运行时只返回当前授权工作区数据 |
| 幂等/CAS | 同幂等键相同命令可重放，内容变化拒绝；旧revision更新冲突且不覆盖新数据 |
| 版本治理 | 草稿可编辑、发布后源码不可改、JS/CSS独立指针正确、归档不会删旧版本；样式运行配置按参考合同处理 |
| 公共模块 | 依赖缺失、循环依赖、注册非法及必需方法缺失失败时不半初始化；禁用不继续执行 |
| URL/导航 | exact/prefix/wildcard及ignoreQuery一致；导航代次阻止过期结果；跨导航document-start在真实WebContents验证 |
| 生命周期 | DOM/load/SPA/user_action按约定执行，重复导航幂等；窗口关闭后订阅和资源释放 |
| 源码完整性 | hash、版本、revision及缓存workspace匹配；失效缓存不能绕过停用或授权 |
| 运行能力 | 默认网络观察与等待可用；无显式授权的拦截拒绝；未知sender/origin不能调用宿主 |
| SDK降级 | 浏览器缺失宿主能力明确拒绝；不会返回Token/Cookie/密码；公共注册和UI回调可清理 |
| 回滚/停用 | 关闭注入保留原窗口和旧登录DSL；切回旧服务/Host保留脚本数据，不影响无关模块 |

尚未进行真实客户端、数据库、云同步或店铺登录验收。源码覆盖表包含相关外围依赖的固定哈希，用于后续逐项接入，不表示这些模块已经迁入当前项目。
