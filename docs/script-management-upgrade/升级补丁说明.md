## 适配范围

1. Host仅增加插件依赖、manifest注册、Vite alias/版本映射和CodeOutlined图标；不复制参考项目的店铺/达人广场注册或生产API代理地址。
2. Host CSS仅复用脚本编辑器到帮助面板的独立样式块，保留此前系统配置样式。
3. 新插件复用参考的Monaco和react-markdown依赖，peer/dev依赖沿用当前项目版本，不引入参考项目整套Antd升级。主补丁锁文件仅新增解析项，不替换已有解析项。
4. 矩阵账号服务仅增加脚本管理、公共资源和运行时路由，沿用当前Bearer/session/workspace/membership/action校验；不整包带入106—111工作台授权体系。
5. Nginx按当前矩阵服务upstream和Header模板增加四组代理：`matrix-account-douyin-scripts`、`matrix-account-public-scripts`、`matrix-account-public-styles`、`script-runtime`。
6. 迁移编号和历史源文件保持参考原样，只携带本功能实际需要的11个迁移；编号间隙不代表必须安装店铺或图片服务。当前迁移器按文件账本处理，不要求连续编号。

## 权限与接口合同

业务脚本管理仅平台工作区；列表和配置查看使用`platform.matrix_account_douyin_scripts.view`，读取业务源码额外使用`content_view`，写操作分别要求create/update/release/activate/archive。菜单使用`menu.platform.matrix_account_douyin_scripts`。

公共JS沿用当前工作区的`matrix_account_scripts.view/manage`权限族；公共CSS沿用参考的`platform.matrix_account_public_styles.view/manage`代码，但权限的workspace_types包括platform/agency/enterprise。公共资源API按workspace过滤。当前管理插件入口仍被平台业务脚本路由限制，不宣称已有机构/企业独立公共资源入口。

写操作沿用`Idempotency-Key`与更新对象的`X-KY-Expected-Revision`、CAS和审计。业务源码读取与公共源码读取的权限模式不同：公共资源详情沿用其view权限，不额外添加业务脚本content_view。详细35个接口、权限及DTO见覆盖清单。

运行时resolve/manifest复验工作区、平台、URL、选择器和版本策略，响应包含源码、SHA256及执行配置；默认网络能力为观察/等待，不接受客户端声明授予拦截能力。运行时API不提供托管执行、任意IPC或数据库访问。

## 数据库与发布顺序

按账本执行以下文件：086脚本/组合版本/平台权限；087独立JS/CSS资产；088标识符；089脚本时机/优先级；090发布时间；091样式时机/优先级/启停；092公共JS；093多匹配规则；094公共JS平台/依赖；096历史源码哈希修复；099公共CSS/权限。

这些迁移不修改旧登录DSL表，不依赖图片服务或店铺登录空间迁移。保留参考源码中的用户引用、角色绑定和审计模式；若目标部署采用分服务数据库角色，需检查新增表归属和GRANT，参考新增迁移没有提供独立角色授权脚本，不能只凭Go构建判断数据库角色可用。

发布顺序：备份目标数据库/配置/旧产物 → 主补丁应用和依赖安装 → 构建/测试 → 数据库账本迁移 → 矩阵账号服务 → Host/代理 → 真实权限和版本操作验收。随后再单独整合桌面运行时消费者，不能将两份补丁一起应用后直接宣布完整注入上线。

## 回滚

尚未发布时可用`git apply -R --check`检查后反向撤销主补丁，并还原依赖安装。已运行迁移后优先回退服务/Host，保留新表、脚本版本和审计数据；不要自动删除新表。误生效时按既有版本资产指针切回已发布版本；桌面执行可使用参考紧急停用开关停止注入。数据库快照恢复需评估发布后新增数据，不作为无损回滚承诺。
