## 关键测试用例

1. build manifest 只含实际 localPlugins；未导入项不列；package version/buildId 缺失为 null。
2. 后台静态 import 映射 loaded，不映射 running；后台 enabled/runtime 为 not_applicable。
3. Desktop active 未 revoked、wc 存活、ready、heartbeat <=6500ms 才 running；heartbeat 超时为 unresponsive；stable phase 不单独通过；无 active 不 fallback builtin。
4. inventory IPC 空对象、64KiB/200 上限、main 顶层 sender 通过；offline/plugin/unknown/子 frame 拒绝；不产生 UI confirmation/challenge。
5. 30s 轮询、90s TTL、失败立即 unknown、单调接收时间过期、generation/AbortController 丢弃迟到响应。
6. service-health 固定映射、2s/5s/并发4/4KiB、redirect/proxy/token/任意 URL/18102 全部拒绝或排除。
7. platform_root 与 `plugin_management.view`/menu 独立校验；未知/空/混合 scope 拒绝；401/403 清理数据。
8. 详情脱敏，services 数组不重复计插件；普通浏览器与旧 Host 显示 not_supported，不生成假 desktop 行。
9. 暂存构建不含 shop import/entry/依赖、env、key、用户数据；现有 desktop-plugin-releases 完整保留。
