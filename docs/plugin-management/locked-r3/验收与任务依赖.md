## 状态验收矩阵

- Desktop `running`：active 存在、未 revoked、webContents 存活、ready=true、heartbeat≤6500ms；phase stable 单独不通过。
- Desktop UI confirmation 独立记录；窗口隐藏/最小化不能把实例改 failed。
- 后台插件静态 import 仅 `loadState=loaded`；`enabledState/runtimeState=not_applicable`。
- 服务状态按 `healthy|unhealthy|timeout|unknown|not_applicable`，版本缺证据为 null。
- `freshness=stale` 只由本地单调接收时间判断；采样失败立即 unknown 并保留 lastSuccess。

## 权限、接口和失败测试
