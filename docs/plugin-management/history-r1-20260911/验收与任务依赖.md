## 运行态判定矩阵

- `running/stable`：必须有当前 session/navigation/revision/digest 的可信 UI confirmation、有效 heartbeat、未过 TTL；HTTP 200、目录存在、静态注册或 release index 单独均不通过。
- `candidate/probation/draining/failed/disabled`：来自 Desktop Host 的真实 phase；若旧客户端无字段为 `not_supported`。
- 服务 `healthy`：只接受固定映射 readyz 在超时内的服务端结果；timeout/取消/权限失败分别保留，不能改写为 healthy。
- 普通浏览器：Desktop 字段为 `not_supported`；缺版本/签名/采样源为 `unknown`；不适用项为 `not_applicable`。

## 权限与 API 门禁

- 菜单 `menu.<workspace>.plugin_management`、页面 `<workspace>.plugin_management.view` 独立；首期仅平台管理员默认授予，不能扩散到其他角色。
- 所有列表/详情请求均校验 Bearer、workspace membership、`plugin_management.view` 和实际 data scope；未知 scope fail-closed。
- 列表 `page=1,pageSize=20`，上限 100；类型、状态、keyword、异常优先筛选；`total` 与同一 predicate 计算。
- 详情不得返回 token、Cookie、Storage、私钥、路径、原始日志或凭据；异常仅安全摘要。

## 范围外与限制

首期不提供安装、上传、卸载、启停、升级、回滚写操作；不采集全设备；不把服务依赖计为插件；不修改店铺模块 D1a/D1b/D2 的未完成状态；正式发行、公证、非 Mac 与物理断电不属于本 R1 验收。
