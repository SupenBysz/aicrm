# 插件管理 R3 锁定记录

状态：R3 已由本地协调交叉复审通过并锁定，进入 I1-I4 实施。

## 锁定澄清

1. `host.enabled` 仅表示开发更新策略许可，不得映射为 `enabledState`。active 实例有效运行时为 `enabled`；明确停止事实才为 `disabled`；其余为 `unknown`。所有 reason 使用受控枚举并映射中文，缺失元数据为 null。freshness 按来源独立；采集失败保留 last-known 行但状态为 unknown；native 不支持时不生成假行。
2. native inventory 输入严格为且仅为一个空对象参数：无参数、多参数、数组、null 或多 key 均拒绝。签名 verified 必须有实际验签证据，否则为 unknown。Membership decision 字段固定为 `actorId/workspaceType/workspaceId/membershipId/grantedRequiredPermissions/dataScopes`，不得发明字段。

## 范围

页面复用 `plugins/ky-system-settings`；只支持 platform/platform_root、菜单 `menu.platform.plugin_management` 和页面 `platform.plugin_management.view`。HTTP 仅 service-health；客户端清单由 Host/Core `PluginInventoryPort` 本地组合。店铺模块 D1a/D1b 待复核、D2 未实现状态保持不变，不参与本次发布。

## 变更规则

API、DTO、状态、权限、scope、IPC、服务映射或发版边界发生变化，必须重新交叉复审、生成新快照和 SHA256SUMS；历史 R1/R2/R3 候选文件只读保留。
