# 平台外观设置交互与派生项目回馈

## 用户任务与作用域

平台管理员选择默认配色、明暗模式，确认效果后保存。个人外观仍由账号偏好独立管理；平台默认只影响跟随平台的用户及未登录入口。已有权限、接口和乐观锁 revision 合同保持不变。

本轮将派生项目实际迭代中的通用交互适配到上游 main，不整体合并派生项目。没有引入客户名称、域名、素材、短信规则、移动客户端、服务器部署配置或数据库迁移。

## 设计与复用依据

- 页面复用 `ListPageCard`，标题与主要保存操作同层；范围说明放在帮助提示中，避免常驻说明框挤占任务空间。
- 复用 `AppearanceControls`、Ant Design 的 Radio、Button、Segmented、Modal、App message。四套主题采用两列选择卡，640 CSS px 以下变为单列；页面最大宽度1200px，正文保留内边距。
- 亮暗效果用现有 `themeVariables` 及系统语义 Token；代表性界面为无业务请求的静态色彩预览，不能产生真实设置操作。
- 继续复用 `BrandLogoLockup` 与原 AI SVG；修复嵌套文字降级不能按高度/宽度缩放、直接文字过度放大的问题。圆点与文字的距离0.44em、圆点尺寸0.32em、圆点与 AI 间距0.16em，AI 几何与92%有效高度比例不变。
- 品牌身份上下文、正式素材加载、品牌名称与图标开关的上游既有/并行改造不在此重复实现；本 PR 不更改品牌数据或自动剥离名称。主题卡中的品牌来源后续由该独立改造统一。

## 操作状态合同

| 状态 | 行为 |
| --- | --- |
| 初始/只读 | 采用当前平台默认；无写权限不显示保存、恢复操作，选择器禁用 |
| 选择配色或模式 | 立即临时预览整页，不调用个人偏好保存，不写登录快照或通知原生窗口 |
| 选回已保存值 | 仍可预览平台效果，但没有差异时保存禁用，避免把个人覆盖误当作平台结果 |
| 恢复默认 | 确认后只改草稿，显式保存后才更改平台默认，保留原 revision |
| 保存中 | 同步互斥禁止重复提交，选择器和恢复操作禁用 |
| 保存成功 | 接受返回 revision、清理草稿、结束临时预览；个人偏好继续生效 |
| 请求失败 | 轻量通知，保留草稿与选择，不把错误插入页面或改变排版 |
| 版本冲突 | 浮层确认是否读取最新配置；取消保留草稿，确认后读取新的 revision，不盲目覆盖 |
| 离开/再次进入 | 结束整页临时预览；未保存草稿按当前账号留在 sessionStorage，再进入可继续编辑 |
| 刷新/关闭 | 未保存时保留浏览器退出提醒；存储受限时继续保留内存草稿 |

Core 的可选 `previewPlatform(value|null)` 只承载临时渲染状态，Host 负责解析与应用，不让插件接管个人会话、原生桥或存储同步。账号切换清除临时预览。
