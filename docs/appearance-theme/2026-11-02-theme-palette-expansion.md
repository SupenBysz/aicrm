# 主题配色扩展实施说明

日期：2026-11-02。状态：已接入当前源码，数据库迁移待部署。

## 支持范围

外观主题支持以下十套配色，每套均提供亮色、暗色和跟随系统模式：

| ID | 名称 | 当前性质 |
| --- | --- | --- |
| `classic-gold` | 经典金 | 现有主题，保持默认 |
| `business-blue` | 商务蓝 | 现有主题 |
| `jade-green` | 翡翠绿 | 现有主题 |
| `graphite-cyan` | 石墨青 | 现有主题 |
| `violet-dusk` | 暮云紫 | 新增 |
| `terracotta` | 赤陶橙 | 新增 |
| `sky-mist` | 天青蓝 | 新增 |
| `pine-forest` | 松柏绿 | 新增 |
| `camellia-red` | 山茶红 | 新增 |
| `slate-fog` | 雾凇灰 | 新增 |

本次从评审预览中移除莓果紫、靛夜蓝、鼠尾草绿，不写入前端、服务端或数据库白名单。

## 实现位置

- `packages/ky-admin-core/src/theme/tokens.ts` 是主题 ID、亮暗语义色与主题选择器的唯一前端色板来源。登录页、公开文档、组件预览和 Host 共用该色板。
- `shared/appearance/appearance.go` 校验平台及个人外观 API 中的主题 ID。
- `apps/aicrm-desktop/src/main/` 与 `src/shared/` 同步 IPC 白名单、桌面窗口底色和浮层投影类型。
- `ops/db/114_expand_appearance_palettes.sql` 扩展个人及平台外观表的主题约束，不更新现有用户记录或平台默认值。

## 兼容与发布顺序

默认仍为 `classic-gold` + 跟随系统。既有个人偏好、平台默认与 revision 不变。新增主题在服务端启用前，数据库必须先应用迁移 114；否则保存新增主题会被表约束拒绝。部署时先确认全部服务、Web、桌面 Host 和桌面包均包含相同主题白名单，再开放选择。

旧版客户端遇到新增主题 ID 时，会按现有前向兼容规则回退显示经典金；数据库仍保留已保存的主题 ID。回退应用版本前，应确保用户可继续使用支持该 ID 的版本，或先将偏好迁回旧版支持的主题，避免旧版呈现与数据库保存值不一致。

## 验收边界

源码实现不代表数据库迁移已应用、服务已部署、桌面包已更新或浏览器视觉已验收。发布时需分别核验个人偏好、平台默认、匿名登录入口、公开文档和桌面窗口；亮暗两组都要覆盖，失败场景不得清除已有偏好。
