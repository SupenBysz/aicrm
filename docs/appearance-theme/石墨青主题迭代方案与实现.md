# 石墨青主题迭代方案与实现

日期：2026-10-30。用户确认方案后实施；当前为本地开发验证，未提交、未推送、未部署。

## 设计目标

参考用户提供的剪映编辑器与首页暗色截图，增加“石墨青”（graphite-cyan），亮色、暗色及跟随系统组成同一配色主题。中性灰承载主要布局，青色仅用于主要操作、焦点和选中反馈。亮色采用冷白与浅灰，独立设计而非机械反色。既有三套主题和用户保存的选择保持不变。

| 元素 | 暗色 | 亮色 |
| --- | --- | --- |
| 页面底色 | #181818 | #F3F5F6 |
| 顶部及导航 | #202020 | #FAFBFC |
| 面板 | #262626 | #FFFFFF |
| 浮层 | #303030 | #FFFFFF |
| 悬停 | #353535 | #EDF1F3 |
| 边框 | #3A3A3A | #DCE2E5 |
| 正文 | #F3F3F3 | #202428 |
| 次要文字 | #ABABAB | #667078 |
| 强调色 | #35D1DB | #087F8C |
| 主按钮文字 | #102629 | #FFFFFF |

导航选中项使用低浓度青色与导航背景混合；普通边框、分隔、工具栏、滚动条使用独立中性色。页面不铺青紫渐变。成功、警告、失败保留语义色。

## 接入范围

- Core主题目录新增第四项，系统配置外观主题与个人偏好通过既有共享控件自动展示；支持平台默认、个人选择、继承平台和系统明暗变化。
- CSS变量与Ant Design同步覆盖背景、边框、选中态、浮层和主按钮；主题预览使用同一色值。切换回既有主题会覆盖石墨青变量，避免残留。
- Host首屏缓存恢复识别新主题，防止刷新降级为经典金。
- Auth/Org共用外观合同接受新标识；权限、CAS修订、个人/平台所有权保持既有合同。
- Desktop窗口背景、窗口外观IPC、宿主浮层投影/动作、版本弹窗及其独立preload均识别新主题。原生WebView占位跟随宿主变量；第三方网页自身的配色由网页决定。
- 不修改客户端凭据存储，不接入系统钥匙串，不增加业务模块或主题管理权限。

## 数据与发布

追加110_graphite_cyan_theme.sql，仅扩展两张外观表的主题CHECK约束，不重写106，不修改保存值、不修改默认主题。不新增表和权限。

部署顺序：备份→迁移110→Auth/Org服务→Web。Desktop新能力需要匹配客户端独立构建/分发。旧Web在遇到未知themeId时按现有兼容规则回退配色；旧服务可能拒绝新的保存值，因此新增主题开始使用后不能仅回退Auth/Org而保留新偏好，回滚前需评估并备份相关设置。禁止直接收紧约束或重置用户偏好。

## 验收要求

1. 系统配置和个人偏好均可选择石墨青；平台继承与个人覆盖互不混淆。
2. 亮色、暗色、系统模式保存、刷新和首屏恢复一致；顶部明暗切换保留themeId。
3. 导航、列表、授权树、表单、Drawer、下拉、错误提示和禁用状态有明确层次；常规边框没有大面积青色染色。
4. 正文、次要文字、主按钮及导航强调文字对比度至少4.5:1；原主题切换无残留。
5. 客户端浮层、版本弹窗、窗口背景和占位配色一致；保持业务WebView实例和输入状态。
6. 迁移可重复执行、保留既有配置；新主题读写/CAS/审计正常，非法主题及继承组合仍拒绝。
