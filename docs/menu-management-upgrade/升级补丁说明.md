# 菜单模块升级补丁说明

本包从 KWW 已实现的菜单模块提取，目标为当前 AiCRM 工作空间提交 `9ecddf2`。参考源码提交为 `339b0af`，包含随后尚未提交的菜单迭代。核心补丁做了必要的目标适配，不重做菜单模块。

## 层划分

| 层 | 内容 | 应用状态 |
| --- | --- | --- |
| prerequisites/01→02→03 | 复用仓库既有 Web 专用窗口基础、插件及桌面宿主补丁；副本与原包哈希对应 | 当前基线尚未合入这些源码，需先依序应用；已包含者不得重复应用 |
| menu-core/01 | 工作台与管理中心目录、工作区授权上限、角色/成员菜单白名单及对应迁移、接口和 Core 类型 | 在目标基线加前置层后可直接应用 |
| menu-core/02 | 目录操作列、名称与图标展示等 UI 收敛 | 核心01之后应用 |
| menu-core/03 | Host/注册表接合、权限分类和中文标签、角色已有权限回显、权限保存并发修复、菜单启停及四列网格的目标适配 | 核心02之后应用；核心组合已验证 |
| webview-conditional/menu-webview-current-feature.patch | 菜单 WebView 配置、会话/协议/脚本资源、桌面打开及会员服务配置接口的条件扩展 | 需完整店铺服务、窗口及脚本运行时依赖；不属于核心构建验收 |
| webview-conditional/02-latest-menu-runtime.reference.patch | 相对339b0af的最新源码增量：通用/工作区覆盖、权限树、受限导航投影、名称图标、区域状态保留、填充布局、初始化/错误/重试及开发隧道兼容 | 独立源码基线参考，不能直接叠加到目标核心；用于依赖齐备后的逐段适配 |
| optional/01-orphan-permission-cleanup.reference.patch | 历史机构企业菜单权限清理迁移124 | 明确可选，先核验目标是否存在相同孤立权限、角色关联和功能替代关系 |

最新参考增量与核心层有共享文件，不能重复应用同一份角色权限或菜单保存改动。所有补丁基线、内容和哈希以 manifest 为准。迁入条件扩展前应在独立分支完成重基和完整构建，不能根据核心验收推断 WebView 已能运行。

## 应用核心

在准确基线的干净分支中依次执行，路径以本包目录为准：

```sh
for patch in prerequisites/01-web-window-foundation.patch prerequisites/02-web-window-plugin.patch prerequisites/03-desktop-host-integration.patch patches/menu-core/01-menu-management-and-authorization.patch patches/menu-core/02-menu-catalog-ui-refinements.patch patches/menu-core/03-host-and-role-permission-adaptation.patch; do
  git apply --check "$MENU_PATCH_DIR/$patch" || exit 1
  git apply "$MENU_PATCH_DIR/$patch" || exit 1
done
```

`MENU_PATCH_DIR` 设置为本目录绝对路径。本示例不会执行数据库迁移、重启服务、推送或发布。应用前确认没有已应用的前置层或其他工作树改动。

共享文件按必要接线适配。核心不引入图片上传、登录持久化重构或完整店铺/达人业务。操作列保持四列，默认折叠的目录采用受控展开状态；相关行为测试没有降级为两列或全部展开。
