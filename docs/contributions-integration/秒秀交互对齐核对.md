## 明确保留的目标适配

- 不移入秒秀名称、公司主体、AI 商业图形、固定品牌组合、Guide 安装/分发、订阅和终端业务。预览保留来源布局与交互，品牌取 KyCRM 平台配置。
- 来源上传后使用公开素材 URL 预览；目标要求草稿素材鉴权，改用受权预览请求与 data URL，含加载失败重试，不能为了外观一致公开草稿。
- 来源回滚按钮位于正文底部，目标项目规范要求窗口级操作位于 Header 右侧；保留独立回滚动作和历史版本选择，执行按钮置于 Header。
- 保留角色权限、缓存隔离、请求代次保护、并发版本及固定 Header 边界。
- 品牌名与应用显示名恢复来源必填校验；未配置机构整体回退平台，版权署名/风格留空继承平台。此处替代提取版“品牌名称也留空”的编辑提示。
- 自动文字素材额外满足目标 PNG 最大宽度 4096 限制；不改服务端上传安全预算。
- 终端无适配器时显示“未接入”，不搬入来源终端数值和底座。
- 素材卡片在两种主题下均采用来源浅色预览面，明确设置深色文字，避免暗色主题继承白色文字后不可读。
