# 页面概览布局全面排查与修复

用户确认：页面概览不得放在表格/筛选卡片内部，要求全面排查修复。

## 排查结果

全仓库检索ListOverview及概览/summary实现，7个业务列表和1个组合示例存在相同嵌套：

| 页面 | 处理 |
| --- | --- |
| 机构管理 | 移入独立overview位置，标题机构概览 |
| 企业管理 | 移入独立overview位置，标题企业概览 |
| 资质审核 | 移入独立overview位置，标题资质审核概览 |
| 用户管理 | 移入独立overview位置，标题用户概览 |
| 邀请管理 | 移入独立overview位置，标题邀请概览 |
| 矩阵账号 | 移入独立overview位置，保留账号概览 |
| 登录日志 | 移入独立overview位置，保留登录概览 |
| 组件中心搜索＋概览＋表格 | 同步真实组合用法和复制源码 |

独立ListOverview组件演示本身不包含业务列表，不做错误迁移。机构/企业行内动态统计属于单行事实，保持原位。菜单、权限、数据字典等配置页面没有添加概览，不机械补统计。

## 统一布局及兼容

ListPageCard新增可选overview属性，DOM顺序为标题/新增操作→独立概览→列表卡片（筛选→表格→分页）。没有overview的现有页面保持原样。概览独立边框、圆角及更紧凑指标间距，跟随主题；没有有效搜索/时间条件时显示全部记录，否则当前搜索范围。

存在可交互total指标时不再重复显示全部记录按钮；邀请、审核等未提供total指标者保留恢复全部操作。API、统计口径、权限、状态联动、页码重置、旧值/撤权处理不变。公共组件规范及组件索引同步更新。
