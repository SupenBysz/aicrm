# 平台品牌表单统一

平台基础信息的“品牌信息”参照机构品牌设计：品牌名称、应用显示名称、图标文字（可选）、应用图标 PNG、文字 LOGO PNG、显示 AI 图标、版权署名、版权风格、实时版权及浅深色顶部预览。上传支持更换、删除；删除后恢复自动生成。生成器、配色、LOGO 与 AI 可见字形尺寸适配共用实现。

公司主体名称、ICP备案仍在“主体信息”。版权署名留空回退主体名称。旧长/短 LOGO 与字体字段保留，迁移不修改已有值；新编辑器保存时同步旧文字字段，兼容旧客户端。旧平台配置在打开时自动作为表单默认值。平台仍是“保存后生效”，不引入机构专用的发布历史流程。

新增迁移 105：平台品牌 JSON 配置与独立图片表；已有客户品牌不自动修改。平台保存继续使用原 revision CAS、基础信息更新权限和变更审计。素材上传后不可公开访问，只有保存后当前配置引用的素材允许公开读取；移除引用后停止公开读取。上传、预览沿用基础信息修改/查看权限，PNG 校验与4MB限制复用机构实现。

平台导航、页面标题、平台登录品牌与未配置独立品牌的机构/企业使用新平台配置。已经发布独立机构品牌的主体继续使用自己的品牌。域名接入开关维持关闭。
