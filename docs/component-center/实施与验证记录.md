日期：2026-10-30，Asia/Shanghai。分支：`feature/component-center-20261030`，实现基线`9c53cba`。用户授权按二次复评文档实施首期P0–P4；本轮完成本地代码、隔离验证与发布准备，未提交、推送、合入或部署准生产。后续高频组件重构、Storybook及原生深化仍不在首期交付内。

## 1. 实际入口与架构

- 入口：管理中心 → 系统设置 → 组件中心；页面路由`/system/components`及`/system/components/:componentId`，由Host加工作区前缀。
- 新插件`@ky/plugin-component-center`只贡献懒加载路由；入口元数据挂在既有系统设置插件，可信目录节点`ky-component-center.catalog`的父节点是`group.ky-system-settings`。没有第二个系统设置组。
- Host依赖、Vite别名、TS路径、插件装配、版本清单、插件目录显示均已接入，插件服务依赖为空。
- 组件中心目录、搜索、分类/状态、详情导航、相关组件、参数、主题/模式/尺寸、初始化/重试/恢复默认、常用API摘要、源码与复制已实现。当前24项均明确标experimental，表示展示条目未完成全部真实业务/原生环境验收，不否定原组件已在现有业务使用。
- 所有交互示例在`component-preview.html`独立文档内，拥有自己的Router、QueryClient、模拟身份/权限/RequestClient。入口没有导入Host main、session、真实外观Provider或Desktop adapter。
- 复用Core原组件及Ant Design；未新建通用StandardDrawer或复制基础控件。抽屉是按既有布局规范的组合范例，不冒充新公共导出。

## 2. 收录与复用事实源

共24个条目、43个状态案例：

- 设计基础：主题色板、文字与图标。
- 基础交互：Button、Input、Select、Switch、Tabs、Form。
- 数据展示：Tag、Table、ListOverview。
- 页面布局：抽屉组合、ListPageCard、DetailPagePanel。
- 反馈：Modal、Alert、Empty、Skeleton。
- 品牌：BrandLogoLockup、BrandAISuffix、AppearanceControls。
- 组合及工具：搜索＋概览＋表格、权限受限操作、runBatchRequests。

`src/catalog/metadata.ts`维护纯数据，运行loader单独维护；示例实际文件为`src/examples/<id>/usage.tsx`，均通过公开导入。默认参数与复制源码一致；调节控制面板不会生成任意代码。单文件示例不依赖组件中心私有fixture；页面展示的是默认示例而非当前全部临时交互状态。

生成器输出`docs/components/component-index.json`和README，包含接口摘要、来源、用途、关联和公共源码指纹，确定性内容哈希无时间戳/随机buildId。Host构建先校验漂移，再从同一usage文件生成24份`public/component-examples/*/usage.txt`；产物按纯文本提供，不提交第二份手写源码。生成目录清理后重建，避免历史tsx副本残留。

检查入口：

```sh
corepack pnpm components:generate
corepack pnpm components:check
corepack pnpm components:test
```

Host构建缓存的inputs包含生成器、索引和组件中心源码，避免缓存命中后跳过新的漂移检查。Root AGENTS.md及项目Skill/创建模块Skill连接复用规则，CONTRIBUTING增加UI复用依据；未修改用户全局Skill、凭据或其他项目。

## 4. 预览隔离与恢复

- 父子消息校验版本、origin、source、实例generation和字段；配置只含固定组件/例子、合法参数及主题，不传真实会话。旧实例/错误来源被忽略；初始化、ack、超时、重试和卸载清理已有测试。
- 模拟请求只接受无body的`GET /demo/options`，每次返回独立固定数据；其他路径、方法和外部URL明确拒绝，无网络兜底。
- 生产Nginx精确匹配预览HTML，`try_files =404`，专属CSP含`connect-src 'none'`、`form-action 'none'`及资源约束；不会对Host/API套用断网策略。源码文本有独立404、text/plain、nosniff和可更新缓存。
- 本地Vite预览仅单独允许明确的loopback HMR WebSocket；生产策略没有HMR或unsafe-eval放行。
- Portal属于独立文档/示例容器；主题用现有Token纯函数，仅写自己的文档样式。未触发真实偏好保存、业务API或原生桥。
- 只运行仓库内可信示例；同源iframe仍具有技术上的父窗口/共享存储访问能力，不将它描述为可运行任意不可信代码的安全沙箱。

## 10. 预览跟随当前主题修复

复用既有AppearanceContext、themeVariables及appearanceAntdTheme，没有新增主题实现。类型检查、8项组件测试（含动态跟随和显式覆盖）、索引漂移检查、Host生产构建通过。仅监听127.0.0.1的模拟Host浏览器验证了石墨青亮/暗下表单按钮、输入框、文字与背景同步，业务请求为0；本轮尚未提交或部署，不能以此替代线上验收。
