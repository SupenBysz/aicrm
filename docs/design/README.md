更新：2026-10-31。适用：KyCRM Web、桌面宿主中的后台页面、业务插件、组件中心及从本基座派生的项目。

本规范从用户任务与操作风险出发约束设计、实现和验收，不是换皮指南。新建或修改 UI、设计页面流程、适配品牌和主题时执行；不意味着历史页面已经达标，也不授权批量修改、发布或跨项目实施。本轮只补齐 KyCRM 文档入口，未另行修改产品界面。

## 使用与冲突处理

- 用户明确需求确定本轮范围；已经确认的业务规则、数据权限和可恢复性不能因视觉统一而被改变。
- 本总则管跨页面一致性；品牌、抽屉、组件复用等专题管其具体场景。组合使用，不以某张截图取代整个规范。
- 历史实施记录是当时事实，不是与当前规范竞争的设计版本。出现规范相互冲突时，先定位冲突点，记录适用场景及兼容方式，再修订唯一事实源；不能在页面私下覆盖后声称已经统一。
- 现有 Token/组件 API 是实现事实。文档中标为“建议”的数值先用于设计评审，不能被描述成仓库已实现的全局 Token，也不能据此无范围地重排历史页面。
- 普通适配和可逆实现不另设审批环节；涉及改权限语义、删除数据、扩大公开范围或真实发布时仍遵循既有授权边界。
