# 交互状态与验收矩阵

与[设计总则](产品交互设计与项目适配总则.md)配套。按改动涉及的路径选择案例；不适用项写原因，不机械为纯文案修改遍历整站，也不能只测成功状态就声称“交互已验收”。

## 1. 状态矩阵

| 对象 | 必测状态/触发 | 应看到的结果 |
|---|---|---|
| 页面 | 初次进入、再次进入、直接打开 URL、返回 | 标题/导航/范围一致；可恢复合理上下文 |
| 列表 | 有数据、真正为空、筛选为空、无权限、失败 | 分别反馈；不给错误显示虚假零值 |
| 查询 | 快速变更条件、重置、回车、旧请求后返回 | 新范围正确、回到约定页、无旧结果覆盖 |
| 概览 | 查询变化、统计刷新、统计失败、无权读数 | 口径/时间明确；失败不冒充 0，权限不泄露 |
| 表格 | 长名称/ID、缺失字段、大金额、多条操作 | 仍可比较、查看完整值、复制原值和执行操作 |
| 批处理 | 跨页、筛选变化、部分成功、超时 | 选择范围清楚，失败项可定位；不盲目重复执行 |
| 表单 | 默认/继承、修改、非法输入、提交中、失败、冲突 | 来源清楚、禁重复提交、保留输入、正确定位错误 |
| 保存模型 | 显式保存、自动保存、草稿发布 | 文案与真实生效时点一致；关闭/撤销语义正确 |
| Drawer/Modal | 长标题、长正文、窄窗、打开/关闭、未保存退出 | 标题与操作可达、正文滚动、焦点返回、草稿受保护 |
| 导航/分段 | hover、focus、selected、expanded、disabled | 各状态可辨，键盘可用；两种滑槽用途保持区别 |
| 品牌 | 两个品牌、亮暗图、缺图/坏图、开关开/关 | 完整 Logo 同源；图标与开关一致，无旧机构闪现 |
| 主题 | 4 套 × 亮/暗、跟随系统、平台/本人覆盖 | 主页面和浮层均适配；首屏不闪旧主题 |
| 权限 | 可读可写、只读、无权、会话过期、切换身份 | 能力与提示正确；不泄露旧工作区数据 |
| 错误恢复 | 断网、重连、请求超时、服务器错误 | 影响范围清楚、可恢复、不重复产生业务结果 |
| 公开文档 | 已发布、未发布、下线、指定版本、匿名 | 仅合同允许内容公开；不暴露草稿/后台编辑能力 |

## 2. 环境与输入维度

| 维度 | 样本 | 记录要求 |
|---|---|---|
| Web | 支持的浏览器及实际版本 | URL、源码版本、视口；不要记录 token |
| 桌面客户端 | 实际系统、安装包/客户端版本、最小与常用窗口 | 窗口按钮/原生浮层/拖动区与业务页面分别检查 |
| 视口 | 320、768、1280、1920 CSS px 中相关样本 | 样本不是强制 CSS 断点；表格局部滚动可接受 |
| 缩放 | 正常比例与 200% 文字/页面缩放的相关场景 | 关键入口、错误与保存仍可达；不作全站合规宣称 |
| 输入 | 鼠标、键盘；支持触控时加入触控 | 检查焦点、可访问名称、误触和非 hover 路径 |
| 数据 | 虚构短/长值、空值、边界值；授权真实只读样本 | 区分模拟视觉与真实接口；不为截图写真实业务配置 |
| 异步 | 慢响应、失败、并发、身份切换 | 不靠增加固定 sleep 隐藏竞争或主题闪烁 |

## 3. 单条验收记录模板

```text
页面/用户任务：
作用域与权限角色：
复用组件/变体：
环境、版本、视口、主题：
前置条件与数据来源（虚构/真实只读/已授权写入）：
操作步骤：
预期状态与完成判据：
实际结果与证据：
异常/恢复路径：
通过/未通过/未验证/不适用及原因：
```

失败项应能复现到具体入口、动作和结果，不写“感觉不统一”。例如“暗色模式移入未选中菜单项，背景与默认状态无法区分”，比“hover 不好看”更可操作。

## 4. 证据边界

- 静态检查：组件来源、Token、索引、路由与权限合同。
- 自动化检查：有价值的状态/边界回归；不写只复述实现的断言凑覆盖率。
- 本地浏览器：真实组件与视觉/输入行为；模拟数据必须标注。
- 线上只读/已授权业务验收：接口、身份、持久化、公开范围和实际入口。
- 安装客户端：需要真实安装版本，不能用 Web 或进程存在替代。

分别记录，不把某一项通过替代其他项。发布摘要同时说明已完成与剩余缺口；没有执行的路径明确写“未验证”。
